# 同程国际具体机场查询

2026-09-14 接入；仅使用公开匿名查询，不发送微信、不创建订单、不索取登录凭据。

官方代码来自 `https://file.40017.cn/iflight/iflight/app.061a10b4a76a72d0efc4.js`。
Book1 先 POST `https://www.ly.com/miflightapi/ts/preload`，JSON 为 `{search: 查询参数}`，再 POST `https://www.ly.com/miflightapi/ts/list`。列表用 `tid` 和 `done` 续查。官网用 `dants[0].ac` / `aants[-1].ac` 过滤机场，以 `fdate` 核对日期，以 `tp` 排含税价、`sp` 排票价。`pc-token: 1`、`t-token: 1` 是公开前端常量渠道标识，不是账户 token。

本程序保留所属城市查询参数，选择1成人、单程经济舱，再按实际机场过滤。城市/机场混合路线先用公开城市目录核实城市所属机场。仅完成且可核验的列表参与比价；预加载若无缓存不能推断没有航班，会继续请求实际列表。每日期最多1次预加载、4次列表请求；首日失败即停止余下日期，不使用城市日历兜底。购票链接中的城市 `para` 与 `departAirportCode` / `arriveAirportCode` 独立保存，全部机场的一端不添加具体机场过滤。

本机实际检查 PVG → CJU、2026-09-21：预加载成功但没有缓存航班，实际列表返回 HTTP 405，2次请求约1.98秒。官方页面还显示登录/安全验证，因此目前不能声称已成功取得该平台的国际机场价。测试夹具为官方 JS 字段约定的最小合成数据，未当作真实报价发布。

## 2026-09-14 继续排查及官方 API 申请

对同一航线补充正常的 HTTP/2 请求验证：系统 curl 的 JSON POST 预加载返回 HTTP 200，`search` 为 `done: 1, result: true, res: []`；JSON POST 和官网 JS 默认的 form Content-Type POST 到实际列表均返回 HTTP 405，分别约 1.33 秒、1.28 秒。因此不能把携程的 HTTP/2 兼容修复直接套用到同程，也不能把预加载的空缓存当作完成查价。官网 JS 仍规定 `list` 使用 POST，且正常请求拦截器会使用网页提供的 `window.h5sign.sign`；本程序没有伪造网页验证凭据或绕过登录、验证码。

官方合作路径可核实，但尚无可直接加入本程序的公开个人免认证查价 API：

- [旧联盟 API 合作介绍](https://union.ly.com/web/unionco) 明确列出国内、国际机票，要求申请方具备网站开发技术团队，接口文档需要联系项目业务经理取得。该介绍没有公开生产接口、国际机场筛选参数、调用额度或价格表。
- [2023 年国际机票合作迁移公告](https://union.ly.com/NewsDetails_334.html) 将国际机票等合作迁至[出行开放平台](https://flights.ly.com/open/home)。当前[同程官方联系页](https://www.ly.com/public/about17u/contactus)的机票合作仍指向这个新入口。新平台宣传免费搭建预订频道，流程包含注册、签署分销合作协议和选择推广类型；这不能证明程序自动查价的生产 API 永久免费。
- [同程商旅系统集成](https://tmc.ly.com/zh/platform/integration) 明确提供 API 直连和免费测试环境，面向企业系统集成；[机票产品介绍](https://tmc.ly.com/zh/products/flight)覆盖国内及国际机票。公开页未说明个人账户能否获批、生产调用是否收费、免费额度、机场过滤字段，也未承诺商旅价等同于同程零售 App 的最低价。
