# Google Flights 公开报价来源

核验日期：2026-09-09。适配文件为 `flightwatch/google_flights_source.py`，类名 `GoogleFlightsProvider`，来源标识 `google_flights`。构造参数与现有来源一致，支持 `cancelled=` 回调。

## 可用方式和依赖

使用 Python 标准库直接读取 `https://www.google.com/travel/flights` 的公开 HTML。查询参数只有 `q`、`hl=en`、`curr=CNY`，不需要用户登录、API key、推送 token、代理或额外 Python 包。

`q` 指定用户选定城市的中文名称、完整出发日期、1 位成人、经济舱和单程。实际核验中 Google 能将“上海”和“东京”识别为城市，返回 SHA/TYO 城市代码，并包括浦东/虹桥及成田/羽田机场。不能唯一确认城市或只识别为某个机场时，适配器会明确报告不支持，以免悄悄缩小或替换用户选择的城市。

开发时用普通 Chromium 对照了 Google 的可见结果；生产运行无需浏览器。最初使用仅 `Mozilla/5.0` 的简单客户端会进入“浏览器不支持”页面。普通现代浏览器请求头能够获得完整搜索页。本实现不处理验证码、登录或同意流程；收到相应页面或 HTTP 401/403/429 时停止本轮 Google 查询。

## 报价与范围

Google Flights 官方说明显示票价包含 VAT/GST 和机场税，行李、信用卡和其他服务可能另收费；具体仍应在预订页面核实。Google 也说明其结果不包括全部航空公司或全部可售航班。参见 [Google Flights 官方帮助](https://support.google.com/travel/answer/2475306?hl=en)。

适配器必须同时看到页面的 `Currency CNY` 标记，以及 `1 adult` 的必需税费包含说明，才将报价标为 `price_basis=total`。目前只支持 CNY、1 成人经济舱单程；往返、明确直飞过滤和其他舱位会报告不支持。

每个出发日期发起一次公开页面请求，返回该页已公布价格的航班中的最低值。未公布价格的航班会记录在提示中；历史价格图、日期推荐、价格走势等数值不进入比较。初始页面可能未列出所有航班，因此界面应称“本次查询最低参考总价”。

## 结构与核对

读取 Google 页面 `AF_initDataCallback` 的 JSON 数据，不执行其中的 JavaScript。开源 [fast-flights parser](https://github.com/AWeirdDev/flights/blob/main/fast_flights/parser.py) 提供了公开嵌入数据的发现线索；本项目据真实页面独立实现解析与查询条件验证，不依赖该库。

- `ds:0`：核实城市实体与三字码、出发日期、单程、乘客数及经济舱。
- `ds:1`：报价数据的城市实体必须与查询相符；只读取航班报价列表。
- Google 自身的机场目录：核实每条航班首末机场属于用户选择的城市，排除附近城市机场及站点。
- 航段：验证首段日期、各段首末机场、中转衔接和日期先后；机场变更但缺乏可核实衔接的组合会被排除。
- 价格：必须为有限正数；币种和含税标签缺失时不进行猜测或自动换汇。

单天网络异常不会丢弃其他成功日期；所有日期失败则来源状态为错误。访问验证、条件或城市不匹配、请求预算用尽，以及用户取消会停止本轮后续 Google 请求。

29 项离线测试覆盖真实精简样本、错误币种/日期/城市/乘客/税费、中转链、未标价、恶意非数字价格、访问验证、请求上限、取消和部分日期失败。命令：

```bash
python3 -m unittest tests.test_google_flights_source -v
```

`tests/fixtures/google_flights_public_sample.json` 来自真实公开搜索结果的精简数据，保留必要位置字段，移除了会话标识和无关页面内容。
