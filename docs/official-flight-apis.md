# 国际机票官方 API 与免费申请

核实日期：2026-09-14。免费注册、免费测试和免费生产查价是不同条件。航班动态、机场目录、供应商上传政策接口也不能代替含税机票查价。

| 平台 | 已核实的官方入口 | 个人免费查价结论 |
| --- | --- | --- |
| 飞猪 AI | [控制台](https://flyai.open.fliggy.com/console)、[快速开始](https://flyai.open.fliggy.com/docs/quickstart) | 目前对个人免费，受配额限制；正式申请需要本人登录和实名认证。官方客户端另有受限体验模式 |
| 同程国际 | [出行开放平台](https://flights.ly.com/open/home)、[API 合作说明](https://union.ly.com/web/unionco) | 国际机票有合作申请入口，需开发能力和商务审核；未公开个人免费生产额度 |
| 去哪儿 | [官方业务合作](https://www.qunar.com/site/zh/Cooperate_4.shtml) | 提供分销及国际机票合作联系渠道；未公开个人免费申请查价 API 或额度 |

飞猪的[官方协议](https://terms.alicdn.com/legal-agreement/terms/common_product_agreement/20260325101742636/20260325101742636.html)明确当前向个人开发者免费提供服务，可限制周期调用配额；年满 18 周岁，实际调用前需完成实名认证。准确额度、有效期及可用权限以本人控制台为准，不能承诺长期无限调用。官方客户端提供的体验模式不等于正式账号权限。

同程联盟的国际机票合作已按[官方公告](https://union.ly.com/NewsDetails_334.html)迁往出行开放平台。[同程商旅](https://tmc.ly.com/zh/platform/integration)明确免费的仅是测试环境，企业商旅库存也不保证等同于同程零售 App 的最低价。去哪儿合作页没有公开生产接口协议，拿到账号后仍需确认是查询去哪儿报价的权限，而非向去哪儿上传供应商产品。

## 项目如何使用飞猪官方接口

1. 在项目目录执行 `bash deploy/install-flight-extras.sh`，安装官方 FlyAI CLI 与可选浏览器。安装不注册账号、不订购付费套餐。
2. 无 Key 时可以使用官方客户端的受限体验查询。长期使用可前往飞猪控制台，以本人账号登录、实名认证并获取正式 API Key。
3. 将 `FLYAI_API_KEY=你的Key` 写入项目本地 `.env`。该文件已经被 Git 忽略，网页下次查询读取；不要把 Key 发到聊天或 GitHub。环境变量中的同名值优先。
4. 页面仍选择“飞猪”，并设置日期、城市全部机场或具体机场。国际机场网页列表无法取价时，程序尝试官方 FlyAI 查询。

Linux 网页服务若已安装，运行 `bash deploy/install-service.sh` 后会优先使用项目 `.venv`；更新正在运行的服务需重启。浏览器路径可用 `PLAYWRIGHT_BROWSERS_PATH` 设置，设置 `FLIGHTWATCH_FLIGGY_BROWSER=1` 才启用普通匿名浏览器；默认不借用用户浏览器账号。遇到网站验证会停止该网页路径，不操作验证码。

## 当前验证到的能力与边界

官方 [search-flight 文档](https://github.com/alibaba-flyai/flyai-skill/blob/main/skills/flyai/references/search-flight.md)支持城市或机场、具体日期/日期范围、舱位和价格排序。程序逐日期查询并核对返回航段的实际机场及日期，不把查询参数本身作为机场匹配证明。

本机用官方 CLI 1.0.16 的公开体验模式查询 2026-09-21 浦东国际机场 → 济州国际机场，约 3.27 秒返回 10 条航班，最低返回 `ticketPrice=390.00`、9C8573，并有飞猪官方购买链接。结果声明体验模式可能限制搜索范围，不能当作全平台最低价。当前响应没有明确税费证明，所以这些报价标为“口径未确认”，仅供参考，不触发含税最低价或目标价微信提醒。获得正式 Key 也不自动改变这个价格判断，仍以实际字段校验为准。

部署后的网页验收：上海全部机场 → 济州国际机场，2026-09-21 至 2026-10-05，飞猪来源约 25.51 秒返回覆盖 15 天的 147 条机场匹配参考报价；最低返回参考为 9/22 的 375 元。页面保留其对应预订链接，同时仍按其他已核实含税来源选每天最低价。该次验收仅查询，未启动监控或发送微信。

受限或缺少价格字段时，按[官方 FAQ](https://flyai.open.fliggy.com/docs/faq)使用返回的 `jumpUrl` 前往预订页核价。程序不会根据页面跳转入口编造票价。请求失败或额度不足会停止该来源剩余日期，其他来源继续。
