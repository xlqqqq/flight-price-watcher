# 机票低价提醒 · 免费查价与微信通知

在网页选择出发地、目的地、最早/最晚出发日期和目标价，并勾选 **7 个真实来源**：携程、同程、去哪儿、飞猪、Google Flights、Kiwi.com、瑞安航空。国内、国际及港澳台航线均可查询，**查价不需要 API key**。各平台覆盖不同，页面逐一显示成功、失败、暂不支持和价格口径。通知可选免费微信服务号、桌面微信、浏览器提醒；服务号需要一次性手机扫码授权，程序自动保存推送凭证。

## 打开页面

Python 3.11+，查询网页只使用标准库，无需 pip 安装。

```bash
cd /home/xel9szh/program/flight-price-watcher
python3 watch.py
```

浏览器打开 **http://127.0.0.1:8765**。也可以执行 `python3 watch.py --web --no-browser`，或用 `--port 8766` 换端口。程序只监听本机，不对外公开微信控制接口。若通过 SSH/VS Code 远程使用，请把服务器 8765 端口转发到本机再打开。

**服务器运行程序时，浏览器里的 `127.0.0.1` 指你的电脑，需要先转发端口：**

- VS Code 远程连接：在“端口”面板点击“转发端口”，填写 `8765`，打开面板显示的本地地址；若本机端口被占用，使用面板实际分配的端口。
- SSH：在你自己的电脑运行下面命令，把 `服务器地址` 换成平时连接这台机器的地址，然后保持 SSH 连接，打开 `http://127.0.0.1:8765`。

```bash
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:8765:127.0.0.1:8765 xel9szh@服务器地址
```

Linux 后台运行可执行 `bash deploy/install-service.sh`，服务异常退出后 5 秒重启。检查和管理：

```bash
systemctl --user status flight-price-watcher
systemctl --user restart flight-price-watcher
systemctl --user stop flight-price-watcher
journalctl --user -u flight-price-watcher -n 50 --no-pager
```

用户服务默认跟随用户登录会话。需要退出所有登录后仍运行时，系统须允许该用户驻留（`loginctl show-user "$USER" -p Linger` 应显示 `yes`；可用 `loginctl enable-linger "$USER"` 开启，具体权限由系统决定）。电脑关机、休眠或 SSH 转发断开仍会影响访问；服务启动不会自动开始机票监控，需在页面点击开始。

页面提供：

- 地点不预设：点击出发地或目的地，输入中文、拼音或城市代码，即时搜索携程收录的城市并选择，例如“喀什 / kashi”“阿勒泰”“布拉格”。输入框带清空按钮，可随时重新选择。
- 53 个常用城市仅用于空输入时的快捷候选，不是可选地点范围。首次远程搜索需要联网；搜索失败会显示提示。列表外城市仍可手动填有效的携程城市代码并选择航线类型。
- 日期选择器：比较连续 1～31 个可出发日期，包含首尾。两个日期表示出发日期区间，**不是往返日期**。
- 查询平台按国内旅行平台、海外旅行平台、航空公司官网分组，新页面默认七家全部选中；已有保存选择会保留，可自行勾选新增来源。最多四个平台并行查询，一家失败不丢弃其他家的结果。
- “查询现在的最低价”：每个出发日期只展示所选平台中可比的最低含税参考总价，标明最便宜的 App 并提供核价跳转；各平台的返回状态和各自最低价仍在上方汇总，不再把同一天铺成多行。若只有一家返回可比总价，页面明确显示“仅1个平台有可比报价”。
- “开始监控”：按所选间隔查询，并按提醒条件发送。每次只能运行一项网页监控，修改前先停止。
- “停止监控”：取消后续轮次及尚未提交的提醒；已经提交给微信的消息无法撤回。

开始监控时，选择会保存在 `data/web-settings.json`；单次查询不保存选择。关闭网页后微信监控仍由 Python 程序执行；退出 Python、关机或休眠会中断监控。重启程序会恢复上次有效选择，需在页面点击开始监控；没有默认启用的示例监控任务。

## Linux 免费推微信，无需桌面或定期互动

选择 **“微信服务号 · 免费 5 次/天”**，使用 Server酱 Turbo 的方糖服务号。按当前提供方说明，无需每隔 24 小时回复机器人，免费额度为每天 5 条；本项目即使遇到试用或会员账号，也只按每天最多 5 次发送尝试运行。

1. 在通知方式中选微信服务号，点击 **“生成绑定二维码”**。
2. 用手机微信扫描，按 Server酱 提示登录/授权。首次使用还需关注方糖服务号并允许接收通知。
3. 点击 **“我已扫码，完成绑定”**，程序获取并保存 SendKey，不要求手动抄写 Token。若官网要求完成首次开通，按页面提示去官网完成后重新绑定；也保留一次性手填 SendKey 的备用入口。
4. 点击 **“发送微信服务号测试消息”**，在手机确认收到；测试占用当天 1 次额度。
5. 选择行程与提醒条件，点击 **“开始监控”**。同一天出发的机票，把两个日期设成同一天。之后由服务器查询并提交符合条件的提醒，可以关闭机票网页。

扫码是一次性授权，后台仍有推送凭证，**不是完全无凭证**。扫码自动接入沿用官网当前公开前端的登录流程，尚不是其承诺稳定的第三方授权 API；接口变化或首次开户步骤无法自动完成时会明确提示，不会假报绑定成功。本地绑定操作不会自动发消息或开始监控。

程序仅发送到方糖服务号，避免跟随账号默认设置误切至需互动的 ClawBot。免费卡片只显示标题，标题包含航线代码、出发日期和价格；完整正文可点击查看，官方免费正文保留 1 天。每天 5 次包含测试与失败，额度用尽继续查价、停止提交发送，次日恢复预算；其他软件的发送也可能占用该账号的免费额度。

SendKey 单独保存于 `data/serverchan-secret.json`，使用本地私密文件权限，不回显到状态接口或写入行程配置。登录会话凭证只保存在内存，绑定完成、取消或过期后清除。若另有已登录的网页会话，使用“生成绑定二维码”仍需本人手机确认新授权。

本次已验证真实匿名二维码及图片下载、模拟绑定/发送；真实授权确认与微信收件仍需用户完成首次绑定测试。具体接入依据、限额和限制见 [SERVERCHAN.md](SERVERCHAN.md)。

## 桌面微信免手填 token 方式

通过**本机已登录的 Windows 微信**，自动向自己的“文件传输助手”发送消息。不使用 PushPlus，不填写 token、微信密码或第三方推送凭证。仍需你正常扫码登录桌面微信；不登录就无法以你的账号发送。

在装有微信的 Windows 电脑上：

1. 复制本项目文件夹到该电脑，安装 Windows x64 Python 3.11～3.13。
2. 打开并登录兼容的桌面微信，保持窗口可见、桌面解锁。
3. 双击 `start-windows.bat`。它创建项目虚拟环境，安装固定版本的免费桌面自动化组件，启动页面。
4. 页面选择“微信文件传输助手”，点“发送微信测试消息”，确认收到后开始监控。

也可以手动安装和运行：

```powershell
python -m pip install -r requirements-wechat.txt
python watch.py --web
```

桌面组件为免费 `wxauto4==41.1.7`，上游标注适配微信 **4.1.8**。微信升级可能导致不兼容；这不是微信官方开放 API，也不承诺其他版本可用。程序会核验登录、精确打开文件传输助手、检查发送结果，不会失败后向当前聊天随意发送。[组件来源与说明](WECHAT_DESKTOP.md)

**当前开发机器没有 Windows 桌面微信，文件传输助手方式不可用；可选上面的微信服务号方式在 Linux 发送。** 页面区分两种方式；桌面发送已通过模拟测试，尚未在真实 Windows 微信上验收。

## 也可选浏览器提醒

在当前 Linux 服务器或不使用微信时，可在页面主动选择“浏览器通知”，然后开始监控。浏览器会在用户点击开始后请求通知权限；不授权时仍在页面中显示提醒。桌面弹窗需要保持页面打开。

选择浏览器提醒是独立功能，**不等于微信推送**。程序不会在微信不可用时悄悄切换渠道。网页提醒与微信提醒分别去重，切换渠道不会因另一渠道已提醒而漏发。

## 价格规则

| 模式 | 行为 |
| --- | --- |
| 最低价汇总 | 首轮及每 24 小时汇总所选日期范围内本次查到的最低参考价 |
| 仅低于目标价 | 严格低于目标价才提醒；等于目标价不提醒 |
| 最低价 + 低于目标价 | 同时启用两种规则，同轮合并提醒 |

已低于目标价后，相比上次提醒再降至少 1 元会提前提醒；未继续明显降价时，至少隔 24 小时再重复。查询间隔最低 10 分钟，建议 3～6 小时。状态保存在 `data/dashboard.sqlite3`，观察记录保留一年。

## 数据来源和范围

| 平台 | 实际查询内容 | 如何参与比较 |
| --- | --- | --- |
| [携程](https://m.ctrip.com/html5/flight/) | 国内/国际公开低价日历 | 使用 `totalPrice` 参考总价 |
| [同程](https://www.ly.com/flights/) | 国内公开航班页面的初始航班列表，逐日查询 | 票价加该航班返回的机建与燃油；只比较可确认费用的航班，国际暂不支持 |
| [去哪儿](https://flight.qunar.com/site/) | 国内/国际公开低价日历 | 国际日历标注含税，参与总价比较；国内日历未含税，仅展示，不触发总价阈值 |
| [飞猪](https://www.fliggy.com/) | 国内逐日航班搜索 | 普通成人经济舱价格加实际税费；排除年龄、会员等有条件价格，中转暂不纳入 |
| [Google Flights](https://www.google.com/travel/flights) | 公开搜索页逐日查询 | 核实1成人、经济舱、单程、CNY及含税说明后参与总价比较；缺少口径或城市不匹配即拒绝 |
| [Kiwi.com](https://www.kiwi.com/) | 城市航线公开单程优惠，日期覆盖有限 | 精确匹配所选日期和机场，成人/税费口径未确认，只展示参考价，不触发阈值 |
| [瑞安航空 Ryanair](https://www.ryanair.com/) | 自营海外航线逐日低价日历 | 动态核对城市机场；保留外币原价并折算人民币，税费口径未确认，只展示参考价 |

各平台分别调用自己的公开网页服务，不把携程报价复制成其他平台报价，也不把购票链接当成已查询成功。所有请求无需登录、cookie 或 API key。微信登录要求与查价独立。

费用与接口核验细节：[同程](TONGCHENG_SOURCE.md)、[去哪儿](QUNAR_SOURCE.md)、[飞猪](SOURCES_FLIGGY.md)、[Google Flights](docs/google-flights-source.md)、[Kiwi](KIWI_SOURCE.md)、[瑞安与其他已核实平台](OVERSEAS_SOURCES.md)。

未含税、税费或成人口径未确认的价格会在平台状态中说明，**不参与最低总价及目标价提醒，也不会进入每天最低价表格**。不使用统一固定税费猜算，不把 0 当免费机票。瑞安外币按 [Frankfurter](https://frankfurter.dev/) 的有日期参考汇率折算；汇率无效、超出7天或请求失败则不换算，支付汇率以官网/发卡机构为准。微信/网页提醒同时带上最低价来源及各平台的参考总价或失败原因。

“最低价”指所选平台、日期中本次返回的可比最低参考总价，并非全网最低或可立即下单的保证。同程初始页面不一定包含全部可售航班，日历也可能缺少缓存。默认查询 1 成人单程、平台默认舱位，不能可靠筛选直飞或往返。网站接口没有稳定兼容性承诺，可能限流或改变；失败会显示原因，最终舱位、税费、行李和可售价格需到购票页核实。

城市选择沿用携程城市目录：上海 SHA、北京 BJS、西安 SIA、东京 TYO、首尔 SEL；搜索机场名时会归到所属城市。去哪儿再用自己的城市建议服务核对名称和城市代码，不会直接假定平台间代码相同；无法确认时显示暂不支持，不替换成别的城市。动态搜索代码和来源见 `flightwatch/city_search.py`，常用候选见 `flightwatch/cities.py`。

## 命令行与兼容入口

```bash
python3 watch.py --dry-run          # 按 config.toml 查真实价格，不发微信
python3 watch.py --test-push        # 免 token 测试本机微信文件传输助手
python3 watch.py --once             # 按 config.toml 查询并通过本机微信提醒
python3 watch.py --loop             # 按 config.toml 持续监控
python3 watch.py --notifier serverchan --loop  # 使用网页已绑定的免费微信服务号
python3 watch.py --demo             # 明确标记的离线模拟，不联网、不推送
```

网页使用页面选择和独立数据库，不覆盖 `config.toml`。命令行示例使用 `provider = "multi"`，可用 `sources = ["ctrip", "fliggy", "google_flights", "kiwi"]` 自选平台，省略时查询全部。全部来源代码为 `ctrip`、`tongcheng`、`qunar`、`fliggy`、`google_flights`、`kiwi`、`ryanair`。`max_requests_per_cycle` 是每个平台每轮的请求上限；同程/飞猪/Google逐日查询，去哪儿和Kiwi还需核对城市与机场，启动前会检查基础预算；瑞安的多机场组合在运行时核验完整请求数量。

命令行退出码 `1` 表示本轮有来源范围限制、缺失报价或错误；仍可产生其他来源的有效提醒，详情见日志。`--loop` 会继续下一轮。退出码 `2` 表示配置或运行条件不满足。

旧 PushPlus / SerpApi 文件仅保留兼容，需要显式选择；新网页不依赖它们的 token，`.env` 可留空。CLI 的 `--notifier serverchan` 优先读取可选 `SERVERCHAN_SENDKEY` 环境变量，否则使用网页保存的本地凭证；与网页共享本程序每日额度。Linux 可用 `bash deploy/install-service.sh` 安装用户级网页服务；登录页面后手动开始监控。该服务不能代替 Windows 交互桌面微信。`deploy/cron.example` 仅保留旧版兼容用途。

## 测试与排错

```bash
python3 -m unittest discover -s tests -v
python3 -m flightwatch.desktop_notifier  # 只检查桌面环境，不发送
```

核心测试覆盖各来源解析、平台失败隔离、税费口径过滤、城市/日期匹配及模拟微信客户端，不发送真实消息。验证记录见 [VALIDATION.md](VALIDATION.md)。

- 页面连接不上：检查 Python 程序是否仍运行，远程会话是否转发了 8765 端口。
- 微信按钮不可用：查看页面环境说明，在 Windows 安装组件并登录兼容版本微信后刷新页面。
- 发送失败不会标记已提醒，下轮可重试。网络/客户端超时发生时发送结果可能未知，重试仍有重复消息的可能。
- 停止监控时若请求已发出，会等待本次网络请求结束，但不再提交尚未发送的通知。
- 缺失日期或接口错误不会被伪装成低价；不要关闭 TLS 验证。真实价格不会用演示数据填充。
